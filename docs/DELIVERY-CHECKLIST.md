## Still unfinished or awaiting external input

- **Dialogue performances:** 66 Tiggy recordings and 15 Benny recordings are missing. The 15 approved Tiggy clips remain bundled at their original pitch/speed. Exact filenames/texts are in [MISSING-ASSETS.csv](audio/MISSING-ASSETS.csv). Missing lines use speech bubbles; Benny does not borrow a different speaker. There is no claim that all game instructions are spoken yet.
- **Physical-device acceptance:** automated desktop/tablet/mobile Chromium and phone WebKit cover the browser flows. Listening/touch/performance on physical iPhone, iPad and Android hardware remains to be confirmed.
- **Broader platform roadmap:** cloud parent accounts/profile sync, native packaging and additional minigames per world remain outside this focused local-play delivery.

The Rive editor rig is not a dependency or a blocker. The running character uses a functional direct 2D vector puppet, not a fabricated `.riv`, static SVG preview or CSS translation of a single character image.
