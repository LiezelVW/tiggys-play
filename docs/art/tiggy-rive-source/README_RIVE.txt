TIGGY / RIVE IMPORT PREPARATION
================================
Source: TIGGY RIG.ai (user's original vector artwork).
Four separate full-body poses: happy, neutral, thinking, laughing.

Each SVG contains named vector GROUPS/LAYERS, preserving the original vector paths and visual stacking.
Open in Illustrator to fine-tune the layers or import the SVG into Rive.

IMPORTANT: These are LAYERED VECTOR ASSETS, NOT A FINISHED SKELETAL RIG.
The source artwork uses overlapping shapes and shared clothing/body silhouettes.
Some grouped components (notably shoes, face, shorts) will need splitting into
independently movable left/right or eye/mouth pieces before clean deformation.
Rive bones, pivots, constraints, state machines and animation must still be created in Rive.

Suggested Rive pivot points:
- Head: bottom centre of neck
- Arms: shoulder junctions, then elbow and wrist
- Legs: hip junctions, then knee and ankle
- Facial controls: individual eyes, brows, mouth

Recommended workflow: start from tiggy_neutral_layered.svg.
Use the other SVGs as expression references, then animate one master character.
